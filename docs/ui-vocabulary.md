# My GPT News UI Vocabulary

Use these names in product discussions, tickets, and implementation notes.

| Label | Component | Meaning |
| --- | --- | --- |
| A | Wordmark | The `MY GPT NEWS` brand link in the header. |
| B | Day timeline | Previous day, selected date picker, and next day controls. |
| C | Search field | Archive search entry point. |
| D | Story stage | The main area showing the selected story. |
| E | Feature image | The selected story's large image. |
| F | Story eyebrow | The selected story's category label. |
| G | Story headline | The selected story's title. |
| H | Story summary | The selected story's concise description. |
| I | Story actions | Read, game, and original-source controls. |
| J | Story rail | The right-hand list of stories for the selected day. |
| K | Rail story item | One selectable row in the story rail. |
| L | Rail scrollbar | The story rail's vertical scroll control. |
| — | Publication timestamp | The story-stage footer that says when the selected story was published or last updated. |
