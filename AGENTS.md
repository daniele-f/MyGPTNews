# MyGPTNews publisher instructions

This repository is a static gaming-news archive. A scheduled GPT publisher may read `PREFERENCES.md`, `SOURCES.md`, and `PUBLISHING.md`, then create or correct exactly one file in `data/editions/` per run. Do not edit application source, workflows, package files, generated indexes, or unrelated editions. Do not fabricate news, images, Steam data, prices, dates, or sources. Preserve existing article IDs when correcting facts.
